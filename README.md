#### refresh-counter

####導入手順
	
1.ローカルに本リポジトリをクローンする。
2.Chromeの拡張機能管理画面 (chrome://extensions/) を開く。
3.右上の [デベロッパー モード] をONにする。
4.左上の [パッケージ化されていない拡張機能を読み込む] をクリックし、クローンしたローカルのフォルダを選択する。
5.Webブラウザでリロードをすると、リロード回数が表示されるようになる。
6.ソースを更新した際は、Chromeの拡張機能管理画面 (chrome://extensions/)の「すべての拡張機能」の項目内にある「Refresh Counter Overlay」のカードの右下にあるリロードアイコン(矢印が回っているアイコン)を押下する。
	
####本機能をOFFにしたい場合
	
1.Chromeの拡張機能管理画面 (chrome://extensions/) を開く。
2.「すべての拡張機能」の項目内に「Refresh Counter Overlay」のような拡張機能があるので、右下のトグルを操作するか左下の「削除」ボタンを押下する。
	
####Tips
	
#####・フォントや見た目のカスタマイズについて
	
content.js の Object.assign の中身を変えることで、見た目を変更できます。
現行仕様(2026/2/5時点)はリロード回数が0回の場合は表示されませんが、0回であっても表示したい場合はObject.assign内の"if (count > 0)"の条件を変更すればリロード回数が0回でも表示されます。
